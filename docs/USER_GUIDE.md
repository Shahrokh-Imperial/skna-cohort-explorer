# User guide

1. Install dependencies and run `bash app/run.sh`.
2. Enter one or more processed-signal paths in the sidebar.
3. Select the event and threshold tables.
4. Choose a recording.
5. Inspect Overview, raw/retained channels, processed SKNA, burst analysis, sequential replay, and results tabs.
6. Export figures or derived tables as needed.

The GUI reads frozen thresholds supplied by the user. Changing replay controls is exploratory and does not overwrite source files.
